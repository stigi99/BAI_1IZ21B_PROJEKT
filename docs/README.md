# Dokumentacja Projektu

Ten katalog zawiera materiały oddawane razem z projektem: sprawozdania,
zrzuty ekranów, diagramy, wyniki narzędzi bezpieczeństwa i dokumentację kodu.

## Najważniejsze Pliki

| Plik | Opis |
|---|---|
| `generated/Sprawozdanie_BAI_Funkcjonalnosci.pdf` | finalne sprawozdanie PDF |
| `generated/Sprawozdanie_BAI_Funkcjonalnosci.docx` | finalne sprawozdanie DOCX |
| `generated/godocs/BAI_GoDocs.pdf` | wygenerowana dokumentacja kodu Go |
| `generated/zap/zap-baseline-report.html` | raport OWASP ZAP Baseline |
| `generated/sqlmap-library-sqli.txt` | wynik SQLMap dla trybu podatnego |
| `generated/sqlmap-library-secure.txt` | wynik SQLMap dla trybu secure |

## Screenshoty

| Katalog | Zawartość |
|---|---|
| `screenshots/functional/clean-*` | normalne działanie funkcji bez ataku |
| `screenshots/functional/attacks/*-vulnerable` | wynik ataku w trybie vulnerable |
| `screenshots/functional/attacks/*-secure` | wynik tego samego scenariusza w trybie secure |

## Diagramy

| Katalog | Zawartość |
|---|---|
| `diagrams/*.svg` | źródłowe diagramy SVG |
| `diagrams/mermaid/*.mmd` | źródła Mermaid |
| `generated/assets/*.png` | diagramy i infografiki w formacie gotowym do README/PDF |

## Materiały Do Nauki

Katalog `nauka/` zawiera plan nauki, fiszki, pytania ustne i checklistę obrony.
Są to materiały pomocnicze dla autorów projektu, ale można ich użyć również
podczas przygotowania do prezentacji.
